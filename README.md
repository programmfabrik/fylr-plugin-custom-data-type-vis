# VIS Fylr plugin

This plugin adds the new data type "VIS" to a Fylr instance, enabling communication between Fylr and the electronic file management system [VIS Suite](https://www.pdv.de/vis-suite/).

## Installation

The latest version of this plugin can be found [here](https://github.com/programmfabrik/fylr-plugin-custom-data-type-vis/releases/latest/download/CustomDataTypeVIS.zip).

The ZIP can be downloaded and installed using the plugin manager, or used directly (recommended).
